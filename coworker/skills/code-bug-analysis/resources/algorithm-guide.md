# 竞赛算法分析指引 (Algorithm Guide)

分析竞赛/算法代码时参考本文件:识别算法类型、计算复杂度、优化建议。

## 常见算法类型识别

| 特征 | 算法类型 |
|---|---|
| 排序/二分/双指针 + 数组 | 基础/查找类 |
| 图结构(邻接表/并查集) + 最短路 | 图论 |
| 状态转移 + 递推表 | 动态规划 |
| 递归分治 + 合并 | 分治/归并 |
| 贪心选择 + 排序后决策 | 贪心 |
| 括号/栈 + 单调性 | 栈/单调栈 |
| 滑动窗口 + 双端队列 | 滑动窗口 |

## 复杂度评估

- 先算**最坏情况复杂度** O(f(n)),标注是否可接受(竞赛常见约束:数据量 n 与时限提示)。
- 检查是否存在**隐藏高复杂度**:如循环内嵌套搜索、每次迭代全量拷贝、递归栈溢出风险。
- 大输入(如 n=10^5/10^6)下, O(n²) 通常不可接受,应提示优化。

## 边界情况必查清单

- 空输入 / 空集 / 空串
- 单元素 / 两个元素
- 全相同元素(去重、排序稳定性)
- 极值:最大/最小值、负值、0
- 整数溢出(尤其 C/C++ int32 乘法/加法)
- 浮点精度(比较用 epsilon)
- 字符串:空串、单字符、超长串、Unicode

## 输出建议

- 指出**复杂度瓶颈具体位置**(行号/循环),不只说"复杂度高"。
- 优化建议给**具体替代方案**(如哈希代替线性查找、前缀和代替区间累加、记忆化代替重复递归)。
- 竞赛代码重点在**正确性与复杂度**,不要用工程代码标准(异常处理/框架)要求它。
